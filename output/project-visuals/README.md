# Project image concepts

Both images are 960 × 640. SVG files are editable originals; PNG files are ready to share. These concepts do not replace the site's current project images.

## ETI screenshot reference

A composition reference for choosing a crop of the real public event page. The interface, colors, copy and open-registration status are illustrative, not a reproduction of the live website. Prioritize the event name and registration action in the actual screenshot. Avoid attendee records.

## IoT connection illustration

A conceptual ESP32 controller and temperature probe, cloud backend, and companion app. Red paths represent cloud communication; the dashed wireless path represents local setup. Hardware appearance, temperature and chart are illustrative, not client product documentation. The neutral technical labels work in both site languages.

Use the SVG for the website to preserve sharp lines at any size. The PNG is provided for sharing and review. At the current 260px project-column width, the icons carry the meaning; the labels are secondary.
